# LipatoS — Parlor

Единый модуль для Foundry VTT: **Parlor Casino Simulator** и тема **Fantasy Tavern**.

## Версия 2.1.9 — настоящие 3D-кубики Dice So Nice! в Farkle

- При включённом **Dice So Nice!** основной бросок Farkle — **реальные физически анимированные 3D-кости**, а не прежние 2D-белые кубики. Парлор показывает только компактные кнопки с номерами костей (1–6) и результатами для выбора комбинации.
- Цвет и материал задаются **только для броска Farkle**, через `Roll.options.appearance` и `DiceTerm.options.appearance`: система standard, синие кости `#2845cc`, белые надписи `#FFFFFF`, синие края `#2845cc`, материал `stone`. Настройки остальных игр и пользователей не изменяются.
- На поддерживаемых версиях DSN временно отключается `hideAfterRoll` в runtime-параметрах на время броска. После того как кости легли, параметры DSN восстанавливаются, а оставшиеся физические 3D-кубики удерживаются до выбора, пропуска или окончания хода; при смене состояния кости очищаются.
- По всему игровому ходу сцена DSN остаётся видимой поверх стола до выбора комбинации. Ранее она опускалась назад сразу после анимации, из-за чего оставались только 2D-кубики.
- Устранён пропуск 3D-показа при первом открытии игры, если игрок уже находится на этапе выбора.
- Если Dice So Nice! отключён, недоступен или не позволяет удерживать реальные 3D-кубики через текущий runtime API, предусмотрено явное возвращение обычных 2D-костей, чтобы выбор и правила Farkle оставались рабочими.
- **Ограничение внешнего API:** положение физического броска Dice So Nice! определяется его настройкой Rollable Area. Parlor не изменяет эту пользовательскую настройку (она статична и не адаптируется автоматически к игровому окну). Для точного размещения 3D-броска внутри правой области нужно сопоставить её с Rollable Area Dice So Nice! на клиенте.
- Добавлены проверки оформления 3D, временного режима удержания, восстановления настроек и 3D-выбора.

## Версия 2.1.8 — устранён конфликт слоёв Farkle и Dice So Nice!

- **Устранены две причины пропадающих костей:** Farkle больше не наследует общий класс `parlor-d6-face` и старый стиль `parlor-ld-die`, а адаптер Dice So Nice! больше не удерживает свой WebGL-слой выше игрового поля на протяжении всей партии.
- Все шесть белых кубиков с чёрными точками теперь представлены самостоятельным HTML-компонентом `FarkleDie.js` с обычными элементами и CSS. Никаких изображений, спрайтов и SVG; элементы с правильным числом точек применяются в зоне бросков, лестнице, истории и правилах.
- В нормальном режиме Farkle находится на уровне **3110**, выше сцены Dice So Nice! (**3100**). Только во время 3D-анимации стол временно опускается до **2300**, после её завершения восстанавливается прежний порядок.
- Управление сценой DSN ограничено отдельным броском. Убрано постоянное удержание сцены при открытии стола, добавлена очистка при закрытии и проверка повторных бросков.
- При отсутствии DSN кубики остаются видимыми и выбираемыми без изменений; игровые очки и история не меняются.
- Новые тесты проверяют генерацию всех шести граней, независимость от общих CSS-классов и временное управление 3D-слоем. Визуальную проверку внутри настоящего Foundry необходимо выполнить после установки.

## Версия 2.1.7 — надёжная отрисовка костей Farkle без внешних файлов

## Версия 2.1.5 — отдельное поле бросков Farkle с Dice So Nice!

- **Новая компоновка:** слева компактный блок подсказки, очков и лестницы отложенных костей; большую правую часть центрального поля занимает самостоятельная зона бросков.
- **Dice So Nice!** интегрирован в Farkle по принципу уже используемого в Parlor адаптера `Dsn3dBridge`. Каждому новому броску с авторитетными результатами GM соответствует локальный показ 3D-анимации DSN (если модуль активен и игрок его не отключил). Синхронизация делается средствами Parlor, а повторной рассылки DSN нет.
- **Результаты остаются на поле.** После анимации те же числа отображаются интерактивными белыми кубиками в зоне бросков вплоть до откладывания, пропуска или завершения хода; выбор отдельной кости не перезапускает анимацию.
- Пока игрок не бросил кости, поле действительно пустое (старые декоративные «пятёрки» убраны). При выборе кости сохраняется её золотая обводка. При отсутствии DSN работают те же интерактивные кубики и оригинальный звук Foundry `sounds/dice.wav`.
- **Ограничение внешнего DSN:** его WebGL-анимация использует собственную настраиваемую пользователем область (Rollable Area) и обычное автоскрытие. Мы не изменяем глобальные настройки и не переносим его общий WebGL-движок в модуль. После анимации результаты остаются на нашем столе в виде тех же белых интерактивных граней, но не физическими 3D-моделями DSN.
- Добавлены автоматические проверки размещения зон, появления 3D-анимации при смене `rollId`, сохранения результатов и локализаций.

## Версия 2.1.3 — отдельный ряд для каждого откладывания и новые правила Farkle

- **Каждый выбор «Отложить кости» теперь занимает новый ряд.** Если в нижнем ряду остались пустые ячейки, следующий выбор всё равно начинается на втором ряду, затем на третьем и так далее. Вместимость уровней снизу вверх: 6, 5, 4, 3, 2, 1.
- Для синхронизации между ведущим и игроками добавлено поле `keptDiceRows` — массив групп костей по действиям откладывания. При передаче хода лестница очищается. Если верхние ряды не вмещают комбинацию, начинается новый цикл заполнения, но очки не обнуляются.
- **Переписан подсчёт очков по новой иллюстрации:** одна 1 = 100, одна 5 = 50; тройки 1 = 1000, 2–6 = 200–600; четыре одинаковых ×2, пять ×4, шесть ×8 от стоимости тройки.
- **Два частичных стрита:** 1–2–3–4–5 = 500 и 2–3–4–5–6 = 750. Полный стрит = 1500, три пары = 1500, две тройки = 2500, четыре одинаковых + пара = 1500.
- Обновлены таблица комбинаций, полные игровые правила на русском, английском и китайском, а также проверки игровых комбинаций и лестницы.
- Сохранены новый набор белых костей, золото/серебро/медь, полноэкранное поле, звук броска и единый стиль Foundry.

### Установка в Foundry

Манифест: https://github.com/Lipatosha/LipatoS-Parlor/releases/latest/download/module.json

Модуль использует ID `parlor`, поэтому сохраняет существующие настройки мира. Отдельно устанавливать прежние Parlor Casino Simulator и Fantasy Tavern **не нужно**.

Поддерживаемая версия Foundry: V13 и V14, согласно манифесту. Работа непосредственно в мире Foundry V14 и с dnd5e 6.0.6 требует дополнительной проверки.

## Разработка и права

Основной код: `scripts/`; встроенная тема таверны: `scripts/tavern/`; стили: `styles/`; переводы: `languages/`.

Исходные лицензии и уведомления об авторстве сохранены в репозитории.

Правила Farkle основаны на распространённом варианте Farkle: https://ru.wikipedia.org/wiki/Farkle_(игра_в_кости). Варианты правил в разных компаниях могут отличаться.
